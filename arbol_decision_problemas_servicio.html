Cada registro enviado desde el dashboard se guardará como una fila nueva en tu hoja de cálculo. Solo tú tendrás acceso de editor. Sigue los pasos una única vez.

PASO 1 — Crear la hoja de cálculo

Ve a sheets.google.com, crea una hoja nueva y ponle el nombre Registros SUNASS. Copia el ID de la URL entre /d/ y /edit.

PASO 2 — Crear el Apps Script

Ve a Extensiones → Apps Script. Borra todo y pega el código abajo, reemplazando TU_ID_AQUI:

function doPost(e) { try { var ss = SpreadsheetApp.openById('TU_ID_AQUI'); var sheet = ss.getSheetByName('Registros') || ss.insertSheet('Registros'); var data = e.parameter; if (sheet.getLastRow() === 0) { sheet.appendRow(['Timestamp','Oficina','Colegio / IE','N° Causa','Causa', 'Actor Clave','Estado','Fecha Envío','Fecha Respuesta','Notas']); sheet.getRange(1,1,1,10).setFontWeight('bold').setBackground('#1a0500').setFontColor('#ffffff'); } sheet.appendRow([ Utilities.formatDate(new Date(),'America/Lima','dd/MM/yyyy HH:mm:ss'), data.oficina||'', data.colegio||'', data.numCausa||'', data.causa||'', data.actor||'', data.estado||'', data.fechaEnvio||'', data.fechaRespuesta||'', data.notas||'' ]); return ContentService.createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({status:'error',msg:err.toString()})) .setMimeType(ContentService.MimeType.JSON); } } function doGet(e){ return ContentService.createTextOutput('OK'); }

Infraestructura Interna Degradada
Sin agua dentro del plantel pese a que la red funciona
▼
Actor clave: UGEL / DRE
Responsable de envío
👤
⚠ Quién debe enviar este oficio
Jefe de Oficina / Jefe de ODS o OAU
Al tratarse de una falla de gestión interna de la IE, la notificación formal a la UGEL es el mecanismo para activar la asignación de presupuesto de mantenimiento. Sin la firma del Jefe de ODS o OAU, la UGEL no queda institucionalmente notificada ni puede exigírsele cumplimiento posterior.
Criterio de identificación
🔍 Verificación previa obligatoria
La red pública presenta presión adecuada en viviendas colindantes, pero dentro de la IE no ingresa agua o el sistema de distribución interno no funciona correctamente. Las causas típicas son: electrobomba inoperativa, válvula check cerrada o trabada, tubería interna obstruida o rota, o falla eléctrica en el sistema de bombeo. La responsabilidad recae en la UGEL/DRE como entidad encargada del mantenimiento del plantel.
Pasos previos al oficio
  • 1
    Medir la presión en el medidor o conexión domiciliaria de la IE para confirmar que la EPS está entregando agua correctamente en el punto de entrada.
  • 2
    Verificar con el personal del plantel si la electrobomba tiene energía eléctrica y si está encendida. Solicitar el último mantenimiento del sistema.
  • 3
    Confirmada la falla interna, el Jefe de Oficina envía el oficio a la UGEL exigiendo intervención urgente.

Actor clave: Gerencia General EPS / Comisaría
Responsable de envío
👤
⚠ Quién debe enviar este oficio
Jefe de Oficina / Jefe de ODS o OAU
Los problemas de calidad pueden derivar en riesgo sanitario inmediato. Los delitos contra el servicio (robo, clandestinaje) requieren acción conjunta con la EPS y eventualmente con la Policía Nacional. Solo la firma del Jefe de ODS o OAU garantiza el peso institucional necesario para ambas vías.
Criterio de identificación por subtipo
🔵
Calidad (turbidez / olor / color): Percepción organoléptica anómala del agua en los grifos de la IE. Requiere toma de muestra por laboratorio acreditado para confirmar el parámetro fuera de norma antes de escalar.
🔴
Robo de medidor: El equipo de medición ha sido retirado o dañado de forma intencional. La EPS tiene obligación de reponerlo sin costo para el usuario conforme a normativa vigente.
🟠
Conexión clandestina: Detección de derivación no autorizada en la conexión domiciliaria de la IE o en la red pública aledaña. Riesgo de contaminación cruzada y afectación de la facturación.
