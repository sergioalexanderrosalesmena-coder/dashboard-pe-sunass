⚙️ Conexión con Google Sheets

Cada registro enviado desde el dashboard se guardará como una fila nueva en tu hoja de cálculo. Solo tú tendrás acceso de editor. Sigue los pasos una única vez.

PASO 1 — Crear la hoja de cálculo

Ve a sheets.google.com, crea una hoja nueva y ponle el nombre Registros SUNASS. Copia el ID que aparece en la URL entre /d/ y /edit.

PASO 2 — Crear el Apps Script

En la hoja de cálculo ve a Extensiones → Apps Script. Borra todo el contenido y pega el siguiente código, reemplazando TU_ID_AQUI con el ID copiado:

// ⚠ REEMPLAZA 'TU_ID_AQUI' con el ID de tu Google Sheet function doPost(e) { try { var ss = SpreadsheetApp.openById('TU_ID_AQUI'); var sheet = ss.getSheetByName('Registros') || ss.insertSheet('Registros'); var data = e.parameter; if (sheet.getLastRow() === 0) { sheet.appendRow(['Timestamp','Oficina','Colegio / IE','N° Causa','Causa','Actor Clave', 'Estado','Fecha Envío','Fecha Respuesta','Notas']); sheet.getRange(1,1,1,10).setFontWeight('bold').setBackground('#003566').setFontColor('#ffffff'); } sheet.appendRow([ Utilities.formatDate(new Date(),'America/Lima','dd/MM/yyyy HH:mm:ss'), data.oficina || '', data.colegio || '', data.numCausa || '', data.causa || '', data.actor || '', data.estado || '', data.fechaEnvio || '', data.fechaRespuesta || '', data.notas || '' ]); return ContentService.createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({status:'error',msg:err.toString()})) .setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { return ContentService.createTextOutput('OK'); }
PASO 3 — Publicar como aplicación web

Haz clic en Implementar → Nueva implementación. Tipo: App web. Ejecutar como: Yo. Quién tiene acceso: ⚠ Cualquier persona. Haz clic en Implementar y copia la URL del campo URL de aplicación web.

⚠ Si ya tienes un deployment anterior: debes crear uno NUEVO para que los cambios del código tengan efecto.
